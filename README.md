# Beyond1 - Beyond Expectations

Professional cleaning and detailing services for automotive, residential, and commercial needs.

**Clean Spaces. Better Vibes.**

## 🚀 Features

- **Automotive Services**: Car detailing, alloy wheel cleaning, engine bay cleaning, stain & odour removal
- **Home Services**: Power washing, carpet cleaning, gutter cleaning, lighting installation
- **Business Services**: Weekly commercial cleaning, flexible scheduling, custom packages

## 🌐 Website

Built with modern technologies for a premium user experience:

- **React** + **TanStack Router** for routing
- **Framer Motion** for smooth animations
- **Tailwind CSS** for styling
- **TypeScript** for type safety

## 🛠️ Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd beyond1
npm i
npm run dev
```

## 🚢 Deployment

See [DEPLOY.md](./DEPLOY.md) for complete Vercel deployment instructions.

```sh
npm run build

```
